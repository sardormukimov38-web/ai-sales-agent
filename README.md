# AI Sales Agent

AI voice agent for automated sales calls — built with Vapi + Make.com

## What it does
- Calls leads automatically
- Qualifies them with a conversation script
- Books meetings into Google Calendar
- Syncs everything to CRM

## Tech stack
- Vapi (voice AI)
- Make.com (automation)
- Google Sheets (lead base)
- ElevenLabs (voice)
